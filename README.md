# 🥤 Açaí no Grau — Sistema de Pedidos

Sistema web de pedidos para lanchonete, com painel administrativo completo para acompanhar as vendas do negócio.

## 📋 Sobre o projeto

O sistema permite que o cliente faça pedidos de forma simples, enquanto o administrador da lanchonete tem acesso a um dashboard com informações estratégicas do negócio, como:

- Produto mais vendido
- Cliente que mais compra
- Faturamento total
- Total de pedidos realizados
- Cadastro de produtos do cardápio

## 🛠️ Tecnologias utilizadas

- JavaScript

## 🚀 Funcionalidades

- [x] Realização de pedidos pelo cliente
- [x] Cadastro de produtos
- [x] Dashboard administrativo com relatórios de vendas
- [x] Acompanhamento de faturamento e total de pedidos

## 💻 Como executar o projeto

```bash
# Clone este repositório
git clone https://github.com/leiddyy/AcaiNoGrau.git

# Acesse a pasta do projeto
cd AcaiNoGrau

# Instale as dependências
npm install

# Execute o projeto
npm start
```
